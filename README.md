# Hotel and Resort Management System

A beginner-level web-based mini project developed as part of the B.Tech CSE 3rd year curriculum.

## Project Description

The Hotel and Resort Management System is designed to provide a simple interface for managing hotel rooms, reservations, guests, check-in/check-out operations, billing, and administrative activities.

## Technologies Used

- HTML
- CSS

## Project Modules

- Public Hotel Website
- User Login
- Room Listing and Details
- Room Booking
- Staff Operations
- Guest Management
- Check-in and Check-out
- Billing
- Administration and Reports
